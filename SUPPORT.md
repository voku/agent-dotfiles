# Support

For a reproducible bug or documentation correction, open an issue with the
agent-dotfiles revision, operating system, invoked native command or setup step,
expected result, actual result and a minimal safe reproduction. Remove source
code, paths, tokens and other sensitive material that should not be public.

For usage questions, describe the coding task and evidence needed. Start with
the [project overview](README.md), [setup](docs/FIRST_INSTALL.md) and
[installation guide](docs/INSTALLATION.md).

Do not report suspected security vulnerabilities in a public issue. Follow the
private reporting route in [docs/SECURITY.md](docs/SECURITY.md).
