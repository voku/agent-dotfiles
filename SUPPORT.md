# Support

For a reproducible bug or documentation correction, open a GitHub issue with the
agent-dotfiles revision, operating system, invoked command or profile, expected
result, actual result, and a minimal safe reproduction. Remove source code,
paths, tokens, and other sensitive material that should not be public.

For a usage question, open an issue that states the coding task and the evidence
you need. This helps keep answers grounded in the existing CLI and shell
contracts rather than adding an unnecessary wrapper.

Before reporting a problem, check the [documentation index](docs/README.md),
[installation guide](docs/INSTALLATION.md), and [shell guide](docs/SHELL.md).
`./bin/agent-dotfiles doctor --profile minimal` is a useful read-only capability
report to include when relevant.

Do not report suspected security vulnerabilities in a public issue. Follow the
private reporting route in [docs/SECURITY.md](docs/SECURITY.md).
