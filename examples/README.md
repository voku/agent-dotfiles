# Opt-in examples

This directory is source material, **not installed agent configuration**. `gitconfig.agent.example` contains only read-only, namespaced aliases for explicitly scoped `git -c include.path=...` invocations. It is neither sourced automatically nor copied to `$HOME`. See [Git evidence](../docs/GIT_CONTEXT.md) for exact usage. Diagnostic tool profiles live separately in `profiles/`.
