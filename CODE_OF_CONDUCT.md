# Code of Conduct

We want `agent-dotfiles` to be a useful place to collaborate on reliable coding
agent tooling. Participate with respect, assume good intent, and keep technical
disagreement focused on evidence and behavior.

## Expected behavior

- Be constructive and specific in issues, pull requests, and reviews.
- Respect different backgrounds, experience levels, and technical choices.
- Share reproducible evidence for claims about correctness, security, or
  productivity.
- Accept correction when tests, review, or new evidence changes the conclusion.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disclosure of
private information, and sustained disruption of collaboration are not welcome.

## Reporting and enforcement

To report a conduct concern, contact the repository maintainer privately through
the [voku GitHub profile](https://github.com/voku). Reports will be handled as
confidentially as the circumstances allow. Maintainers may ask for context,
request changes to participation, remove content, or restrict participation to
protect the community.

This code applies in all project spaces and when someone represents the project.
For technical help, see [SUPPORT.md](SUPPORT.md). For a security vulnerability,
follow [docs/SECURITY.md](docs/SECURITY.md) instead of publishing details.
